# ROCK-PAPER-SCISSORS
# 🌌  Rock Paper Scissors

A visually stunning, animated Rock-Paper-Scissors game set in a cosmic theme. Built with HTML, CSS, and JavaScript, this interactive game lets you challenge a computer opponent with glowing animations, gradients, and classy particle effects.

---

## 🚀 Game Description

**Cosmic
Rock Paper Scissors** isn't just a hand game — it's an interstellar battle of wits and reflexes. With liquid-like glowing effects, gradient UI elements, and smooth hover animations, this game gives a cosmic twist to the classic childhood game.

Choose Rock 🪨, Paper 📄, or Scissors ✂️ and outsmart the galaxy's AI brain. The background and visuals shift like space auroras while you play!

---

## 🎨 Features

- 🌈 Liquid gradient UI with glowing effects
- 🎮 Fully responsive and animated
- 👽 Cosmic-themed layout with floating particles and trees
- 🧠 Computer AI opponent
- 📱 Mobile-friendly design

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (with animations and gradients)
- JavaScript (Vanilla)
